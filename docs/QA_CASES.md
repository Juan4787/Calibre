Cambiar únicamente lo indicado. Validar Dataset y llamar audit; usar OR-01/02/05 para expected. ## Matching: grafo que el operador debe poder dibujar

| Caso                                     | Configuración / esperado                                      | Nunca / oráculo / severidad                                                                                                                                               |
| ---------------------------------------- | ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1→1                                      | clave carrier+reference, C1→S1; esperado100                   | No usar candidato de otro carrier; OR-05/CRITICAL                                                                                                                         |
| 1→N líneas del mismo concepto            | C1=40,C2=60→S1; duplicate_fields vacío; un E100,A100          | No cobrar E100 dos veces; OR-03+05/CRITICAL                                                                                                                               |
| 1→N conceptos independientes             | base100 y espera20→S1; reglas distintas                       | No deduplicar por remito; OR-05/CRITICAL                                                                                                                                  |
| N→1 consolidado                          | group por lote; S1peso10,S2peso20; sum×2→60                   | `attr(weight)` no puede elegir un peso cuando difieren; OR-02+05/CRITICAL                                                                                                 |
| N→M mismas operaciones                   | M líneas sobre idéntico grupo y concepto suman A una sola vez | No inferir reparto de cada cargo por envío; OR-03/CRITICAL                                                                                                                |
| N→M grupos que se solapan                | C1→S1,S2 y C2→S2,S3 mismo acuerdo/concepto/moneda             | REVIEW de ambos; no duplicar obligaciónS2; OR-05/CRITICAL                                                                                                                 |
| Sin match                                | C1 referencia inexistente                                     | REVIEW conservando importe; no eliminar ni FAIL; OR-03+05/CRITICAL                                                                                                        |

## Fuzz estructurado de importación

Corpus en `tests/fuzz_corpus/`: entradas pequeñas, manifest con hash/expected, mapping explícito y recipe. Sin archivos de clientes, macros activas ni bombas reales. Cada mutación cambia un mecanismo y conserva el resto de la estructura válida.

| Mecanismo / corpus a construir                 | Handling objetivo y observación actual                                                                                                                                             |
| ---------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| CSV delimitador/quotes/multilínea/BOM/encoding | Con mapping correcto normalizar conservando referencia/raw/filas físicas; quote sin cerrar→error de archivo; encoding incorrecto→error, no remplazo de bytes                       |
| CSV número ambiguo/agrupador inválido          | Rechazo de fila con campo/raw; nunca parsear parcialmente. `1.234` significa1234 con mapping argentino y1.234 con punto decimal                                                    |
| Headers repetidos/vacíos                       | Columna mapeada repetida/ausente→error de mapping; columna irrelevante vacía no hace que se elija por índice accidental                                                            |
| Línea/columna enorme                           | Respetar25MiB/200001filas/250columnas y límites de strings; excepción clasificada; prueba subprocess con RAM/tiempo, no crearGB                                                    |
| XLSX números texto vs numéricos                | Texto respeta locale; numérico usa token XML original y estilo/tipo; no usar float como oracle                                                                                     |
| Fórmula, error, caché, vínculo externo         | Mapped formula/error→rechazo incluso con cachedvalue; no recalcular ni abrir enlace; unmapped formula no se ejecuta                                                                |
| Celdas vacías/merged                           | Required vacío→rechazo; merged no rellenar hacia abajo. Si cliente necesita fill-forward, nueva política explícita pendiente                                                       |
| Hidden rows/sheets y filtros                   | Hoy iter_rows incluye filas ocultas y permite hoja elegida; preview no destaca ocultamiento. Expected seguro: scope explícito y aviso verificable antes del piloto con esos libros |
| Varias hojas/nombres Unicode                   | Exigir sheet si hay>1, buscar nombre exacto; no seleccionar primera. Sheet usada y nombre del archivo en provenance                                                                |
| Seriales/épocas/estilos                        | Pares manuales de la matriz temporal; conservar tipo y raw suficiente. No generalizar cobertura sólo porque una fecha normal pasó                                                  |
| Precision/exponentes/XML numérico              | 1000000000000000.01 exacto;1e999999→rechazo; expansiόn acotada antes de format; fuente original preservada                                                                         |
| ZIP truncado/entradas duplicadas/DTD           | Error clasificado; cero ejecución/red. Tamaño declarado y expansión real se prueban por separado                                                                                   |
| XLS BIFF/cachés/fechas/texto/codepage          | Sin aceptación explícita→error; con aceptación→warning permanente. El lector usa valores guardados; no afirmar que distingue fórmula/cache ni recupera decimales perdidos          |

## Seguridad local: ensayos concretos

Todos los ensayos usan directorio temporal y un canary `outside.txt` con hash previo/posterior. No apuntar payloads a archivos reales del usuario.

| Vector                                        | Plausibilidad / severidad                    | Ensayo y mitigación esperada                                                                                                                                                                                                   |
| --------------------------------------------- | -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Path traversal en UploadFile                  | Media/CRITICAL                               | filename `../../outside.txt`, ruta Windows y absoluta; blob por hash, nombre reducido; canary intacto                                                                                                                          |
| Zip slip en bundle                            | Media/CRITICAL                               | Entrada `../outside.txt`, duplicada y `C:\\outside.txt`; verificador rechaza ruta; ninguna extracción de ZIP ajeno. Actual chequeo Path es dependiente del SO: matriz Windows pendiente                                        |

Prueba de generalidad: mismos nombres de IDs/tablas y distinto precio entre A/B no pueden compartir caché; cargar arquetipos en orden inverso y comparar economía. Registrar archivos tocados y horas de onboarding: cambios esperables son mappings/acuerdos/fixtures; modificación del core exige una abstracción con al menos dos ejemplos distintos y un contraejemplo. No convertir automáticamente una necesidad de un cliente en default global.
